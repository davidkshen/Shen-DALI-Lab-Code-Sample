# Data availability

The datasets used by this research notebook were supplied through lab work. They are not included here and are not available for redistribution through this repository.

This restriction also applies to saved outputs that could reveal data or results: molecule/compound tables, SMILES lists, docking records, fingerprint matrices, selected-feature exports, train/test splits, predictions, models, graphs and figures.

## Inputs referenced by the code

| Input category | Expected information |
|---|---|
| Compound/activity table | A molecular representation such as `SMILES`, an identifier such as `BindingDB_MonomerID`, and an activity measurement. |
| Descriptor table | An identifier column such as `Name` and fingerprint columns generated by the descriptor tool. |
| Prepared regression table | Numeric predictors and the target named `pIC50` in the legacy analysis. |
| Docking-feature table | The docking predictor columns referenced in the code, aligned with the activity records. |
| Intermediate experiment files | Authorized split, feature-selection and comparison files produced by earlier notebook branches. |

The original code uses several alternative CSV filenames. Those names describe expected local inputs; their presence in the code does not provide the files or permission to distribute them. A filename containing a public database name does not establish that the lab's assembled/processed table may be shared.

For IC50 values genuinely measured in nanomolar units, the conversion implemented in one branch is `pIC50 = -log10(IC50_nM * 1e-9)`. Inputs must be positive and their units checked. A separate branch renames an existing mixed activity field; that is not a validated conversion between pKd, pKi and pIC50.

Hard-coded selected fingerprint identities have been replaced by `REDACTED_FEATURE_###` placeholders. These placeholders are not executable substitutes for the original column names. Use an authorized feature selection or regenerate features from permitted data for any new analysis. The private identity mapping is not included.

No synthetic or public replacement dataset has been bundled. An independently obtained dataset would require its own provenance, license, target harmonization and evaluation; it would not reproduce the original private study automatically.
