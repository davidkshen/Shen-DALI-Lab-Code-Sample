# Visualization examples

Both images are synthetic illustrations generated for this public code sample. No lab molecules, feature selections, activity measurements, predictions or performance scores were used.

The heatmap displays random binary feature flags for dummy molecule labels. The violin plot displays randomly generated illustrative scores; no models were trained to produce them. Neither figure reports a research finding or establishes a model ranking.

They can be regenerated with `python scripts/make_example_figures.py`. The original notebook's plotting methods remain in its source cells. These previews were added during AI-assisted repository presentation and were not outputs of the original lab analysis.
